# 书籍分类 / 标签 / 系列回填清单

日期：2026-11-12  
用途：给当前缺少元数据的书补分类、标签、系列，让 `/categories/`、`/tags/`、`/series/` 从“空页”变成可用内链。  
状态：**已于 2026-11-12 执行**。《我的手记》保留公开；《百年孤独-精装版》《我的书籍》《一本无名的书籍》改为草稿；《霸王别姬》作者暂未改动，仍待人工核对。

## 建议分类体系

先固定 5 个大类，避免分类过多导致每个分类只有一本书：

| 分类 | 适用内容 |
|---|---|
| 小说 | 长篇小说、短篇、文学经典 |
| 商业财经 | 投资、金钱心理、商业、经济 |
| 历史 | 世界史、通史、历史人物 |
| 计算机 | 编程、系统、教材、技术 |
| 随笔 | 个人记录、散文、生活随笔 |

标签优先复用，不要为每本书造太多一次性标签。建议每本 3–6 个，优先使用能覆盖 2 本以上书籍的词。

## 先处理的数据质量问题

1. **《百年孤独》和《百年孤独-精装版》疑似重复**  
   建议下架/合并精装版，保留一个 canonical 页面，避免重复内容互相竞争。

2. **《花钱的艺术》分类是“小说”**  
   这本书更符合“商业财经”，建议改分类，并把它作为“财经系列 #1”。

3. **《我的手记》《我的书籍》《一本无名的书籍》疑似测试/占位内容**  
   标题和作者都不像正式书评页。建议补真实内容或下架；在没处理前不要急着给它们做分类页。

4. **《霸王别姬》作者写的是“张丰毅”**  
   这本书通常关联李碧华原著；先核对作者字段，避免结构化数据出错。

5. **《我的手记》作者为空**  
   要么补作者，要么下架，不建议让空作者页进入公开站点。

## 填完后

1. 后台逐本保存，先不要批量改数据库。
2. 预览 `/categories/`、`/tags/`、`/series/`，确认每个分类/标签下至少有一本书，重点标签尽量有 2 本以上。
3. 运行本地部署脚本重新生成静态页：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/deploy-webhostmost.ps1
```

4. 部署后检查：
   - `/categories/`、`/tags/`、`/series/` 不再接近空页
   - 书籍详情页出现分类/标签/系列链接
   - sitemap 中新增的 taxonomy URL 可访问
